# DayZPulse

Панель управления серверами DayZ для Windows: локальный веб-интерфейс,
служба Windows и значок в трее. Работает с собственным модом **DayZPulseCore**,
который отдаёт данные о игроках и принимает команды.

## Возможности

**Мультисерверность.** Раздел «Все серверы» — карточки-ноды: их можно перетаскивать
(позиции сохраняются), соединять проводами по порядку, менять зум колесом и сдвигать
пустое место; двойной щелчок сбрасывает. Список «Мои серверы» живёт в боковой панели.
У каждого сервера своя папка, свой блок портов (игра, Steam Query, RCON…), свой токен
мода, свои конфиги, резервные копии и расписание. Все разделы работают в контексте
выбранного сервера.

**Управление процессом.** Запуск, остановка и перезапуск серверов, живая
консоль с отправкой команд в stdin, автоперезапуск после сбоя с защитой от
циклов падений, метрики CPU и памяти, приоритет процесса.

**SteamCMD и Steam.** При первом запуске панель сама скачивает SteamCMD в
`<папка сервера>\steamcmd` и прогревает его анонимным входом, чтобы клиент
обновился до входа в аккаунт. После создания владельца открывается окно входа
в Steam с поддержкой Steam Guard: достаточно один раз ввести логин, пароль и
код — сессия сохраняется в каталоге SteamCMD, и код больше не запрашивается.

**Игроки (через мод).** Онлайн с координатами и состоянием выживания,
история треков для карты, живая карта с транспортом, база игроков
(сессии, наиграно, убийства, K/D), килфид и чат из админ-логов, нарушения
античита, заметки и список наблюдения, обратный канал команд моду
(лечение, телепорт, погода, время, выдача предметов, личные сообщения).

**Обслуживание.** Файлы конфигурации с резервной копией при сохранении,
резервные копии данных сервера с восстановлением, расписание задач
(бэкап, рестарт, команда), просмотр журнала аудита.

**Windows-служба.** Панель работает как служба (автозапуск при загрузке,
без входа в систему) или как приложение с иконкой в трее. Если панель уже
поднята службой, трей работает пультом к ней.

## Безопасность

Панель рассчитана на локальный доступ, поэтому защита встроена по умолчанию:

- **Владелец создаётся при первом запуске** — учётных данных по умолчанию нет.
- Пароль хранится как **PBKDF2 (SHA-256, 600 000 итераций)**; минимум 8 символов
  и две группы символов (буквы, цифры, знаки).
- **CSRF**: двойная отправка токена плюс проверка `Origin` для всех
  изменяющих запросов.
- **Строгий CSP**: скрипты только из собственных файлов, без inline и `eval`,
  поэтому внедрить код через данные нельзя.
- Запрет встраивания в iframe, `nosniff`, запрет внешних ресурсов,
  ограничение частоты запросов и отдельный лимит на попытки входа.
- **Токен-сессии** в HttpOnly-cookie, аудит действий, ограничение доступа
  к файлам в пределах папки сервера.

## Требования

- Windows 10/11 или Windows Server
- **.NET 10 Runtime** (для сборки — .NET 10 SDK)
- Сервер DayZ Standalone (`DayZServer_x64.exe`)
- Собственный мод `@DayZPulse` на сервере — для раздела «Игроки»

## Сборка

```powershell
dotnet build                                  # отладка
./build.ps1                                   # публикация в ./publish
./build.ps1 -SelfContained -SingleFile        # один файл со встроенным рантаймом
```

## Запуск

```powershell
DayZPulse.exe                    # приложение с иконкой в трее
DayZPulse.exe --console          # то же, с журналом в консоли
DayZPulse.exe --port=8730        # другой порт веб-интерфейса
DayZPulse.exe --data-dir=D:\dzp  # свой каталог данных
```

Откройте `http://127.0.0.1:8730` и создайте владельца панели.

### Служба Windows

```cmd
install-service.cmd      :: от имени администратора
uninstall-service.cmd
```

Или вручную: `DayZPulse.exe install-service` / `uninstall-service` /
`start-service` / `stop-service` / `service-status`.

## Настройка

**1. Папка сервера.** В настройках сервера укажите базовую папку (по умолчанию
`C:\DayZServer`). Оттуда берутся исполняемый файл, `serverDZ.cfg` и `profiles`.

**2. Мод.** Установите `@DayZPulse` и добавьте его в запуск как серверный мод:

```
DayZServer_x64.exe -config=serverDZ.cfg -servermod=@DayZPulse
```

Панель сама пишет `profiles/DayZPulseCore/config.json` с адресами и токеном —
пересобирать PBO не нужно. Файл перезаписывается при сохранении настроек
связи, поэтому правки вручную по адресам и токену не сохранятся.

**3. Добавление сервера.** «+ Добавить сервер» в боковой панели. Панель
подберёт свободный блок портов; при пересечении портов сохранение отклонится.

## Каталоги

| Что | Где |
|---|---|
| Настройки панели | `%ProgramData%\DayZPulse\settings.json` |
| Журналы панели и серверов | `%ProgramData%\DayZPulse\logs` |
| Резервные копии | `%ProgramData%\DayZPulse\backups\<сервер>` |
| Состояние трекера | `%ProgramData%\DayZPulse\tracker-<сервер>.json` |
| SteamCMD и сессия Steam | `<папка сервера>\steamcmd` |

Каталог можно задать переменной `DAYZPULSE_DATA` или ключом `--data-dir`.

## Важно

- Останавливайте сервер перед правкой его файлов: DayZ держит блокировки.
- Проверяйте конфигурацию после массовых изменений — панель делает `.bak`
  рядом с каждым перезаписанным файлом.
- Мод — отдельный компонент: без него раздел «Игроки» не наполнится, а
  остальные разделы продолжат работать.
