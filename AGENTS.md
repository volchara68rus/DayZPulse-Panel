# DayZPulse — инструкции для агента

## Git

- **Не делать `git push` без явной команды пользователя.** Пуш только по прямой просьбе
  («пушь», «можно в гит», «запушь»).
- Коммитить локально можно, если это уместно, но по умолчанию изменения оставляются
  незакоммиченными и ждут подтверждения.
